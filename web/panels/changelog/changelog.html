v2.2.0
  • 按住题号上滑＝加入待做池，下滑＝即刻开始计时：题号颜色跟手渐变（蓝 / 绿），到阈值后锁住；已在池中、池已满、已有别的题在计时会变红并用 toast 说明
  • 圆点新增四种状态色：待做池玫瑰、计时中蓝（只有正在计时才呼吸变蓝）、挂起橙（与「会了没写」同色），带呼吸提示；两色都可在主题编辑里改
  • 统计改版：总题数 / 已做 / 本周 / 连续天数，近 210 天热力图（格子颜色＝当天完成的最高难度，深浅＝当天题量）、累计完成曲线、难度分布百分比
  • 随机跳题直接复用主列表的题目行（标签 / 难度 / 状态一致），多一列「题单位置」，点一下定位回原题单
  • 搜索新增「笔记」模式：全文匹配笔记内容并给命中词高亮
  • Font Awesome 改为本地内置，断网也能显示图标
  • 修复：两个「题单管理」字样重叠（标题栏现在显示当前题单与进度）
  • 修复：在弹窗里框选文字、鼠标滑出卡片就被判「点击外部」而关窗
  • 去掉 toast 的假毛玻璃（真背景模糊只留给弹窗遮罩）
  • 标签改版：笔记任意位置写 #颜色 标签（如 #red 莫队 分块、#FFEE00 取模），空格即换下一个标签，同一颜色后可连写多个，换行或下一个颜色标记结束；支持常见颜色名 / 中文色名 / 十六进制，标签各自着色
  • 侧栏宽度可拖动调整：拖右边缘改宽，双击边缘恢复默认，宽度会被记住
  • 修复：在训练区（日常）改状态后，主列表的圆点状态不跟着刷新
v2.1.0
  • 模拟赛支持「定时开始」：预约后到点自动开赛，无需手动卡时间
  • Trick 库全面支持 Markdown（标题 / 列表 / 引用 / 代码块 / 链接等）
  • Trick 支持美元公式：$...$ / $$...$$（内置本地 KaTeX，离线可用）
  • 题单支持单栏 / 双栏切换，组头始终独占一行
  • 笔记第一行以 # 开头即可定义标签，标签直接显示在题目上
  • 题目右键新增「即刻开始」：加入进行区并计时；进行区满时自动把第一题打回待做池
  • 多选新增「复制到剪贴板」，支持带 / 不带难度；批量打开严格按界面从上到下
  • Ctrl+数字标记难度在复选框聚焦时不再失效，且候选变化后自动从第一题重新开始
  • 题单记忆组的开合状态与滚动位置；待做池 / 挂起区固定高度并支持滚动
  • 「最近完成」每日自动清空，投入时间同步归零
  • 非洛谷 / CF / AT 题目统一打开 Virtual Judge；新增设置 → 快捷键指南
  • 主题商店改为预览卡片布局；过长题号自动省略
  • 修复自定义主题切换后残留行内 CSS 变量的问题
